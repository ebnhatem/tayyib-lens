# Governance

- **Maintainer:** Ahmad Hatem (ebn Hatem) — @ebnhatem
- **Advisory review:** before the v1.0 tag, a named scholar advisory board reviews
  the universal-prohibitions file and a sample of profile rules.
- **Decision policy:** maintainer merges; evidence corrections that change a verdict
  require a locator and a second reviewer when available.
- **Versioning:** SemVer — MAJOR (verdict changes / profile re-scoping),
  MINOR (new rules/sources), PATCH (corrections, wording).
- **Rejected-words naming policy** applies to any new file, rule, or doc
  (no governor/judge/creator/criterion role claims — see PRD taxonomy).
