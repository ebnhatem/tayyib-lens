# Visual safe-rewrite patterns
## spatial-scene
Convert a person-centric request into a scene: the place, the era, the light — no figure.
<!-- e.g., "the Prophet's childhood street" -> "7th-century Meccan alley, dawn, no figures" -->
## faceless-silhouette
Full figure with no facial features; partial concealment.
## abstract-ornament
Replace reverenced/venerated object with geometry, arabesque, calligraphy.
